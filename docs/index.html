How to use this index

Links are evidence—not a green light.

Every entry points to an issuing government source. Start with the federal baseline, then read the current state text, definitions, exceptions, dates, and agency guidance for the exact product and address. County, city, tribal, venue, licensing, tax, payment, and product rules can add requirements.

The current reviewed coverage includes New Jersey, Massachusetts, California, Texas, Oregon, Wisconsin, Nevada, Washington, Kentucky, Virginia, Tennessee, Minnesota, and other state records; use the filter below to inspect every dated source entry.

The current 50-record dataset is documented in the August 3 provenance release. The Zenodo record is an earlier historical source-record snapshot; it is not a claim that the DOI contains the current manifest. Neither record is independent legal review or a location approval.

Not legal advice and not a location approval.

The index does not say a product, machine, or venue is lawful. Laws and guidance can change. Confirm the real inventory and street address with qualified counsel and the responsible authorities before operating.
